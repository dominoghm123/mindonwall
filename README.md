## 🧠 What is Mind on Wall?

Mind on Wall is a **digital collage wall** for creative minds. Pin photos, notes, and stamps on an infinite canvas. Connect them with ropes. Watch your ideas find each other.

Not a workspace. **A thinking space.**

### ✨ Why?

Most tools force you to organize first, think later. Notion wants databases. Milanote wants projects. Sticky notes want... nothing — and that's the problem.

Mind on Wall gives you a wall. You pin things. You connect them. Ideas grow organically — messy, personal, and yours.

### 🎯 Use Cases

- **Travel Journaling** — Pin photos, tickets, and notes. Connect places with ropes. See your trip as a story, not a list.
- **Design Thinking** — Scatter inspiration, sketches, and references. Let connections emerge naturally.
- **Research & Mapping** — Collect fragments. Build relationships. Switch to Connection Map to see the big picture.
- **Daily Brain Dump** — No templates. No folders. Just your wall.

### 🖥️ Try It Now

 **[Open Mind on Wall](https://mindonwall.vercel.app)**

No download. No install. Open in your browser and start pinning.

### 📖 How to Use

#### Basic Operations

| Action | How |
|--------|-----|
| **Add a photo** | Click the bottom toolbar → "Add Image" |
| **Add a note** | Click the bottom toolbar → "Add Paper" → choose Note / Torn / Sticky |
| **Add a stamp** | Click the bottom toolbar → "Add Stamp" |
| **Move an object** | Drag it anywhere on the wall |
| **Resize** | Drag a corner handle |
| **Rotate** | Drag the top handle |
| **Connect two objects** | Click the Rope tool → click two pins |
| **Edit paper text** | Double-click the paper |
| **Attach stamp to paper** | Right-click stamp → "Attach to Paper / Photo" |
| **Change wallpaper** | Click the bottom toolbar → "Wallpaper" |

#### Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl/⌘ + Z` | Undo |
| `Ctrl/ + Shift + Z` | Redo |
| `Delete / Backspace` | Remove selection |
| `Esc` | Cancel / close menus |
| `Ctrl/⌘ + A` | Select all |
| `M` | Toggle Connection Map |
| `+ / −` | Zoom in / out |
| `0` | Reset zoom to 100% |

#### Connection Map

Switch to the Connection Map from the top bar to see all your objects as nodes and ropes as connections. Click two node endpoints to connect them. Right-click a line to change color or delete it.

#### Sharing

Click "Share link…" in the top bar to generate a shareable URL. Others can view your wall in read-only mode.

## 🧠 Mind on Wall 是什么？

Mind on Wall 是一个**数字拼贴墙**。把照片、笔记和印章贴到无限画布上，用 Rope 连线，让想法彼此相遇。

不是工作台，是**思考空间**。

### ✨ 为什么？

大多数工具让你先整理、再思考。Notion 要数据库，Milanote 要项目，便签什么都不要——而这就是问题所在。

Mind on Wall 给你一面墙。你贴东西，你连线。想法自然生长——混乱的、私人的、属于你的。

### 🎯 使用场景

- **旅行手帐** — 贴照片、票根和笔记。用 Rope 连接地点。把旅行看成故事，而不是清单。
- **设计思维** — 散落灵感、草图和参考。让关联自然浮现。
- **研究与 Mapping** — 收集碎片，建立关系。切换到 Connection Map 看见全局。
- **日常灵感** — 没有模板，没有文件夹。

### ️ 立即体验

👉 **[打开 Mind on Wall](https://mindonwall.vercel.app)**

无需下载，无需安装。打开浏览器即可开始拼贴。

### 📖 使用指南

#### 基本操作

| 操作 | 方法 |
|------|------|
| **添加照片** | 点击底部工具栏 → "Add Image" |
| **添加纸片** | 点击底部工具栏 → "Add Paper" → 选择 Note / Torn / Sticky |
| **添加印章** | 点击底部工具栏 → "Add Stamp" |
| **移动物件** | 在墙上拖拽 |
| **缩放大小** | 拖拽角落手柄 |
| **旋转** | 拖拽顶部手柄 |
| **连线两个物件** | 点击 Rope 工具 → 点击两个 Pin |
| **编辑纸片文字** | 双击纸片 |
| **将印章贴到纸片上** | 右键印章 → "Attach to Paper / Photo" |
| **更换墙纸** | 点击底部工具栏 → "Wallpaper" |

#### 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl/⌘ + Z` | 撤销 |
| `Ctrl/ + Shift + Z` | 重做 |
| `Delete / Backspace` | 删除选中 |
| `Esc` | 取消 / 关闭菜单 |
| `Ctrl/ + A` | 全选 |
| `M` | 切换 Connection Map |
| `+ / −` | 放大 / 缩小 |
| `0` | 重置缩放到 100% |

#### Connection Map（关系图）

从顶栏切换到 Connection Map，可以看到所有物件作为节点、Rope 作为连线的关系图。点击两个节点端点即可连线。右键连线可改色或删除。

#### 分享

点击顶栏的 "Share link…" 生成可分享链接。其他人可以只读模式查看你的墙。
