# Feature Map — MVP

## 产品一句话

让用户用手帐式摆放与连线，把零散记录沉淀为一张可分享的墙和一张可回看的关系图。

## 首发场景

旅行回顾：6 张图片、3 个地点标签、4 条短句和 2 张票根式 Paper 组成一面示例墙。产品不局限于旅行；同一套语法未来可用于灵感 Mapping、设计研究与日常记录。

## MVP 主路径

`样例/上传图片 → 贴到白墙 → 添加 Paper/Stamp → Rope 连两个自动 Pin → Reveal Connections → 可选 AI → 导出 PNG`

## 必须完成

- Picture、Paper、Stamp、Rope 四类物件。
- Picture/Paper 自动出现一个位于上边缘中点的 Pin；Rope 只连接有效 Pin。
- 拖拽、缩放、旋转、删除、Paper 文本编辑、Rope 关联说明。
- 白墙/Connection Map 双视图、本地保存、两种 PNG 导出。
- 用户主动触发的百炼 Qwen 建议：关系命名、回顾问题或故事标题。

## 刻意不做

- 地图、Zine、Live Recap、外部内容采集、账户、云同步、协作和素材商城。
- 自由手撕、物理引擎、自由绘画、完整视频剪辑。
- AI 自动改动用户的墙，或生成完整游记。
- Sound 与 Video；它们属于后续版本的主体类型。

## 完成定义

评委能在 3–5 分钟内用样例或自己的图片完成一面墙，建立至少一条有说明的 Rope，切换到 Connection Map，并导出任一视图的 PNG；AI 不可用时，上述流程仍可完成。
