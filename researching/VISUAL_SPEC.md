基于冻结 PRD 的视觉与交互实现指南。

## 1. 颜色体系

| 便利贴默认黄 | `#FFF3B0` | 经典便利贴黄 |

`#FFF3B0`（黄）、`#FFB3BA`（粉）、`#BAFFC9`（绿）、`#BAE1FF`（蓝）、`#E8D5FF`（紫）、`#FFD8B1`（橙）、`#F5F5F5`（灰白）、`#2C2C2C`（黑/深色模式）

## 2. 物件尺寸规范

### 默认尺寸（创建时）

| 物件 | 默认宽度 | 默认高度 | 最小尺寸 | 最大尺寸 |
|---|---|---|---|---|
| Picture | 240px | 自适应（维持宽高比） | 80×80 | 600×600 |
| Paper（普通/撕边） | 200px | 120px | 60×40 | 500×300 |
| 便利贴 | 140px | 140px | 80×80 | 300×300 |
| 胶带 | 180px | 30px | 80×20 | 400×40 |
| Stamp | 80px | 80px | 40×40 | 200×200 |
| Pin | 16px | 16px | 固定 | 固定 |

### 缩放手柄

- **四角手柄**（8×8px 圆形）：等比缩放（按住 Shift 强制等比，默认即等比）
- **边缘手柄**（12×6px 矩形）：单独调整宽/高（拉伸模式）
- 选中态：1px 虚线边框 `#4A90D9` + 8 个手柄

### 旋转手柄

- 选中物件顶部上方 20px 处显示旋转手柄（小圆环图标）
- 旋转角度以 15° 为吸附增量

## 3. 墙纸纹理

6 种墙纸选项，通过 CSS 实现（不依赖外部图片）：

| 名称 | 实现方式 |
|---|---|
| 无墙纸 | 纯色 `#FAFAF8` |
| 白色基础纸 | 纯色 `#FFFFFF` + 极细的 1px 间距网格线（opacity 3%） |
| 米色基础纸 | 纯色 `#F5F0E8` + 微妙暖色调 |
| 浅色粗纹纸 | `#F0EBE3` + CSS 噪点纹理（SVG filter: feTurbulence） |
| 水彩纹理纸 | `#F2EDE4` 底色 + 大面积柔和水彩渐变斑块（CSS radial-gradient 叠加） |
| 牛皮纸 | `#D4B896` + 纤维纹理（CSS repeating-linear-gradient 模拟纸纹） |

所有墙纸纹理使用 CSS 实现，便于运行时切换。

## 4. 浮窗布局规则

### 工具栏（底部）

- 默认状态：缩小的横条（高 32px，宽 180px），居中底部，圆角 16px
- Hover 展开：高 56px，宽自适应（向左右延展），显示图标按钮
- 背景：`rgba(255,255,255,0.95)` + `backdrop-filter: blur(12px)` + 1px border `#E0E0E0`
- 工具图标：24×24px SVG，间距 12px
- 选中便利贴时：额外显示颜色选择区（8 色圆点 + 自定义色盘入口）

### 素材托盘（左侧）

- 默认状态：缩小的竖条（宽 32px），纵向居中左侧，圆角 16px
- Hover 展开：宽 200px，显示上传区域 + 已上传图片网格（3 列）
- 背景同工具栏（毛玻璃白）
- 上传按钮：虚线框 "点击上传" 区域

### 顶部浮窗

- 固定顶部，高 48px，左右贯通
- 左：← 返回总览页
- 中：墙名（可点击编辑）
- 右：保存状态指示（绿点=已保存 / 灰点=离线）、墙纸设置下拉、Connection Map Tab
- 背景：`rgba(255,255,255,0.9)` + blur

### AI 助手浮窗（右侧）

- 默认隐藏，点击顶部"AI 助手"按钮展开
- 宽 320px，高自适应（最大 60vh），右侧固定
- 背景同浮窗风格
- 内容：任务类型选择（4 个按钮）+ 操作对象显示区 + AI 输出区 + 采纳/取消按钮
- "点选 Rope"模式时，浮窗显示引导文字，墙上 Rope 高亮可点击

## 5. Rope 视觉

- SVG 贝塞尔曲线（二次方贝塞尔），两端点为 Pin 的世界坐标
- **物理弧度（悬链线模拟）**：
  - 下垂量 `sag = k * (L - d)`，其中 `k=0.3`（松弛系数），`L` 为绳索自然长度（创建时 = 初始距离 × 1.2），`d` 为当前两点距离
  - 两点越近 → `L-d` 越大 → 弧度越大（绳子松驰下垂）
  - 两点越远 → `L-d` 趋近 0 → 弧度越小（绳子绷紧）
  - 贝塞尔控制点：X = 两点中点，Y 偏移 = sag
- 线宽：2px
- 默认颜色：`#8B7355`（麻绳色）
- 选中态：颜色加深 `#5D4E37` + 宽度 3px
- 拖拽中（创建 Rope 时）：半透明虚线 + 跟随鼠标

## 6. Pin 视觉

- 16×16px 图钉图标（SVG）
- 造型：白色圆形钉头（#F5F5F5，径向渐变模拟光泽）+ 下方金色短针柄（#C9A84C，2px 宽，4px 长）
- 正视角度，无投影，极简但可识别为图钉
- 参考：`researching/pin_sample/` 中的白色圆头金色针柄图钉
- 位置：默认物件上边缘中点；拖动后跟随局部坐标

## 7. 排版

- 正文：`system-ui, -apple-system, sans-serif`，14px
- Paper 内文字：手写风格字体（中文：`"LXGW WenKai"` / 英文：`"Caveat"`），16px
- 墙名：无衬线体 16px bold
- 浮窗标签：12px，`#666`

## 8. 连接高亮

- 点击 Paper 时，与其关联的 Rope 和物件高亮显示（边框加粗 + 发光效果）
- 高亮颜色：`#4A90D9`（蓝色发光）
- 用于帮助用户感知物件间的关联关系

## 9. Stamp 视觉处理

- 所有 Stamp 使用 `mix-blend-mode: multiply` 模拟真实印章盖在纸上的效果
- 印章边缘有轻微不规则（生成时已包含颗粒纹理）
- 附着在 Paper 上时，Stamp 的 z-index 高于 Paper 文字层
- Stamp 选中态：虚线边框 + 缩放手柄

## 10. 拖拽尾巴线（Rope 创建中）

- 从 Pin 出发，跟随鼠标的临时 SVG 线
- 样式：`stroke: #8B7355`，`stroke-dasharray: 6 4`（虚线），`opacity: 0.6`
- 鼠标靠近另一个 Pin 时：该 Pin 发光提示（`#4A90D9` glow）
- 松手完成连接 / 松手取消

## 11. 总览页

- 网格布局展示墙面卡片（3 列，响应式）
- 卡片尺寸：280×200px
- 卡片内容：墙纸缩略 + 墙名 + 物件数量
- 选中态：蓝色边框
- "管理墙"模式：卡片左上角出现 checkbox
