# Vibe & Interaction Constraints

## 气质

这是一面缓慢生长的私人白墙，不是生产力白板，也不是自动写游记的 AI 工具。目标用户有记录与表达欲，厌倦快节奏内容消费。

## 不可违背的视觉规则

- 核心界面是可更换墙纸的白墙。
- 所有物件**没有投影**。
- 质感来自撕边、透明胶带纹理、印章颗粒、图钉造型与 Rope 的松弛弧度。
- 整体是干净的平面杂志拼贴感，不做拟真的桌面或重物理模拟。

## 物件语言

| 物件 | 表达作用 |
| --- | --- |
| Picture | 照片、截图和图像化碎片 |
| Paper | 可编辑 Note、撕边纸、标签、票根、胶带等纸类素材 |
| Stamp | 情绪、主题或节奏标记 |
| Pin | 贴墙时自动出现的固定点；不是独立工具 |
| Rope | 从 Pin 到 Pin 的带松弛弧度的思考路径 |

## 叙事原则

用户的选择、摆放、批注与连线本身构成叙事。AI 仅在用户请求时，给已有关系命名、提出回顾问题或建议一个标题；它的输出必须被标为建议，不能改动墙面。

## Map 视图

Map 是当前墙面的只读投影：以统一节点尺寸、更高对比度和清晰标签帮助阅读关系。它不应修改保存的物件位置、尺寸或旋转。
