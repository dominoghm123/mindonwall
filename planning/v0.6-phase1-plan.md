## Phase 1 Features

### Feature A: Edit / View Mode Toggle (TopBar)

**目标：** Wall 内页顶部栏新增"Edit / View"切换按钮，一键切换两种模式。

#### Data Model Changes

1. **useUIStore.ts 扩展**
   ```typescript
   interface UIState {
     // ... existing fields
     editMode: boolean;  // NEW
   }

   interface UIRActions {
     // ... existing methods
     toggleEditMode(): void;  // NEW
     setEditMode(mode: boolean): void;  // NEW
   }
   ```

2. **App.tsx 初始化**
   - 默认 `editMode: true`（编辑模式）
   - 总览页（overview）不需要 editMode

#### Component Changes

3. **TopBar.tsx — 新增 Toggle Button**
   - 位置：右侧区域，在 "+ New Wall" 之前
   - 图标：Edit 模式 = `✏️`，View 模式 = `👁️`
   - 样式：Ghost button（透明背景 + hover #F0F0F0 + subtle shadow）
   - 标签："Edit" ↔ "View + Comment"
   - disabled 状态：Total overview mode 不可见

4. **Edit Mode vs View Mode 行为差异**

   | 组件 | Edit Mode (true) | View Mode (false) |
   |------|------------------|-------------------|
   | TopBar "Manage" | Visible | Hidden |
   | TopBar "+ New Project" | Visible | Hidden |
   | TopBar "+ New Wall" | Visible | Hidden |
   | BottomToolbar panels | Visible, interactive | Hidden |
   | Canvas object drag | Enabled | Disabled |
   | Canvas object resize | Enabled | Disabled |
   | Canvas object rotate | Enabled | Disabled |
   | Rope连线 | Clickable pins | Pins hidden (visual only) |
   | Context menu | Full options | Hide delete/duplicate/rename |
   | Selection box | Visible | Hidden |

5. **InfiniteCanvas.tsx — 条件禁用交互**
   - 当 `editMode = false`：
     - 物件不响应 pointer events（`pointerEvents: 'none'` on wrapper divs）
     - 画布仍可 pan/zoom（不影响浏览体验）
     - Selection box 不显示
     - 右键菜单仍可用但 hide editing options

6. **ContextMenu.tsx — 条件隐藏 items**
   - 新增条件 props: `{ showEdit: boolean }`
   - Edit items (Delete/Duplicate/Rename) 只在 `showEdit=true` 时渲染

### Feature B: Drag-to-Merge → Project Auto-Creation

**目标：** 将 WallCard 拖到概览页空白区域时自动创建新 Project，无需手动点击"+ New Project"。

#### Interaction Flow

```
User drags WallCard → drops on empty grid area
  ↓
Drop target highlights (dashed border + fade color overlay)
  ↓
Automatically creates new Project (default name: "Untitled Project")
  ↓
Moves dragged wall into this new project
  ↓
Inline rename input appears in Project header (autoSelect text)
  ↓
User types name → Enter to confirm / Esc to keep default
```

#### State Changes

7. **useOverviewStore.ts 扩展**
   ```typescript
   interface OverviewState {
     // ... existing fields
     addProject(name: string, color?: string): string; // returns projectId
   }
   ```

   ```typescript
   addProject: (name: string, color?: string) => {
     const id = `project-${Date.now()}-${Math.random().toString(36).slice(2, 8)}`;
     const projects = get().projects;
     const newProject = {
       id,
       name: name.substring(0, 50),
       color: color || PROJECT_COLORS[Math.floor(Math.random() * PROJECT_COLORS.length)],
       wallIds: [],
       createdAt: Date.now(),
     };
     set({ projects: [...projects, newProject] });
     return id;
   }
   ```

#### Component Changes

8. **OverviewPage.tsx — Grid drop zone detection**
   
   ```tsx
   const [dragOverEmpty, setDragOverEmpty] = useState(false);
   const gridRef = useRef<HTMLDivElement>(null);

   <div 
     ref={gridRef}
     className="overview-grid"
     style={{ position: 'relative' }}
     onDragOver={(e) => {
       e.preventDefault();
       const target = e.target as HTMLElement;
       // If over grid container itself or a non-card element, highlight for creation
       if (target === gridRef.current || !target.closest('[data-wall-card]')) {
         setDragOverEmpty(true);
       } else {
         setDragOverEmpty(false);
       }
     }}
     onDragLeave={() => setDragOverEmpty(false)}
     onDrop={(e) => {
       e.preventDefault();
       if (dragOverEmpty && dragWallId) {
         // Create new project and move wall into it
         const newProjectId = get().addProject('Untitled Project');
         moveWallToProject(dragWallId, newProjectId);
         setDragWallId(null);
         setDropProjectId(newProjectId); // Will trigger inline rename
       }
       setDragOverEmpty(false);
     }}
   >
     {/* Empty area overlay */}
     {dragOverEmpty && (
       <div className="create-project-overlay">
         <span>+ Drop here to create project</span>
       </div>
     )}
   </div>
   ```

9. **New InlineRenameInput 组件** (`src/components/shared/InlineRenameInput.tsx`)
   
   Props:
   - `initialName: string`
   - `onChange: (newName: string) => void`
   - `onSubmit: (name: string) => void`
   - `placeholder?: string`
   - `autoFocus?: boolean`

   Behavior:
   - Controlled `<input>` with autoFocus + selectAll on mount
   - onKeyDown: Enter → submit, Escape → submit with default name
   - onBlur: auto-submit (no cancel option, prevents ghost inputs)
   - Max length: 50 chars, clamp visually but allow typing
   - Style: border-bottom dashed, minimal padding, focus ring matches brand

   Usage in ProjectHeader:
   ```tsx
   function ProjectHeader({ project, isNew }) {
     const [editing, setEditing] = useState(isNew);
     
     if (editing) {
       return (
         <InlineRenameInput
           initialName={project.name}
           onChange={handleNameChange}
           onSubmit={(name) => {
             renameProject(project.id, name);
             setEditing(false);
           }}
           autoFocus
         />
       );
     }
     
     return (
       <h3 onClick={() => setEditing(true)}>
         {project.name}
         <PencilIcon size={14} />
       </h3>
     );
   }
   ```
