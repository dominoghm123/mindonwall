## Feature Details

### Feature 1: Edit / View Mode Toggle (TopBar)

**目标：** Wall 内页顶部栏新增"编辑 / 阅览"切换按钮，可一键切换两种模式。

**当前状态：**
- App.tsx `viewMode` 只有 `"overview"` | `"wall"` | `"map"` 三种视图
- 编辑和浏览混合在一起（所有工具栏、右键菜单都可见）

**实施计划：**

#### Data Model
```typescript
interface AppState {
  viewMode: 'overview' | 'wall' | 'map';
  editMode: boolean;  // 新增: true = 编辑, false = 阅览
}
```

#### Changes
1. **useUIStore 扩展：**
   - `editMode: boolean`
   - `toggleEditMode(): void`
   - `setEditMode(mode: boolean): void`

2. **TopBar 组件：**
   - 右侧添加 Toggle Switch（Edit ↔ View + Comment）
   - View mode 图标：`EyeOutlined`
   - Edit mode 图标：`PencilOutlined`
   - 样式：Ghost button，hover shadow

3. **编辑模式依赖项隐藏（当 editMode = false）：**
   - TopBar：Hide "Manage", "+ New Project", "+ New Wall"
   - BottomToolbar：Hide rope/paper/stamp panels
   - Canvas：Disable rotation/resizing/dragging on objects
   - ContextMenu：Hide delete/duplicate/rename options
   - Pin/Rope：Not clickable (visual only)

4. **View + Comment：**
   - View mode 下显示 comment bar 在每个 object 下方
   - Comment list dropdown (skeleton, no backend yet)
   - Floating "Add Comment" FAB

**工作量估算：** 1.5 天

### Feature 2: Auth Flow Optimization

**目标：** 区分注册用户 vs 老用户，未登录时限制编辑但不阻断浏览。

**当前状态：**
- AuthModal + AuthGuard 已集成
- AvatarMenu 双状态（Sign In / 头像菜单）
- Cloud sync 已连接 Supabase
- 未登录仍可创建墙 + 编辑（无数据隔离）

**问题：**
- 未注册用户首次进入没有注册引导
- 老用户不需要强制登录即可浏览，但编辑时提示登录更友好
- 没有"仅浏览"vs "登录后可编辑"的清晰分离

**实施计划：**

#### Auth State Flow
```
Unvisited User → Show "Getting Started" modal with Sign Up CTA
Returning Guest (no account) → Browse freely, toast prompt when trying to edit
Registered Logged-In → Full access (edit + sync)
Registered Logged-Out → Local storage persists, but sync disabled
```

#### Changes
1. **App.tsx 启动逻辑：**
   - Check if user has visited before (`localStorage.getItem('hasVisited')`)
   - First visit: Show welcome modal ("Create account to save your walls")
   - Set flag after first close: `localStorage.setItem('hasVisited', '1')`

2. **AuthModal 改进：**
   - Add "Continue as Guest" button (for returning users)
   - Social login primary, email/password secondary
   - Remember auth state across sessions (Supabase auto-refresh token)

3. **Permission Guard:**
   - When `editMode = true` and `!isAuthenticated`:
     - Show toast: "Sign in to save changes"
     - Temporarily switch to view mode
   - Save action (Ctrl+S): trigger login flow if not authenticated

4. **AvatarMenu 增强：**
   - Already shows avatar menu when logged in
   - Add "Sync Status" indicator (cloud icon green/red dot)
   - Distinguish "Guest" vs "Member" display

5. **Cloud Sync Behavior:**
   - Guest mode: All data stays in localStorage (isolated from any cloud)
   - Logged-in: Auto-sync on every change (debounced 30s) + manual sync button in Settings

**工作量估算：** 2 天

### Feature 3: Drag-to-Merge: Wall → Project Auto-Creation

**目标：** 将 WallCard 拖到空白区域时自动创建 Project（而不是先弹 confirm merge）。

**当前状态（v0.5 B1/B2）：**
- B1: Drag WallCard to Project header → drops into existing project
- B2: Drag WallCard onto another WallCard → merges two walls

**缺失：**
- 拖到空白的 overview 区域时没有反应（应自动创建新 Project）
- 创建后没有让用户命名 Project 的输入框（默认 "Untitled Project"）

**实施计划：**

#### New Interaction Flow
```
1. User drags WallCard to overview grid empty space
2. Drop target: highlight grid background (dashed border + fade color)
3. On drop: create new Project automatically, move WallCard into it
4. Inline rename field appears in the new Project header (auto-select text)
5. User types name → press Enter to confirm, Esc to keep default
6. Project name saved to useOverviewStore.projects[]
```

#### Changes
1. **OverviewPage.tsx 改进：**
   ```typescript
   const [dropTarget, setDropTarget] = useState<'project' | 'create-new' | null>(null);
   
   // Grid container: detect drag-over on empty areas
   <div 
     ref={gridRef}
     onDragOver={(e) => {
       e.preventDefault();
       // If over empty area (not a card), show "create new project" overlay
       if (e.target === gridRef.current || (e.target as HTMLElement).tagName === 'DIV') {
         setDropTarget('create-new');
       } else if ((e.target as HTMLElement).dataset.dropZone === 'project') {
         setDropTarget('project');
       }
     }}
     onDrop={(e) => {
       e.preventDefault();
       if (dropTarget === 'create-new') {
         const newProject = { id: nanoid(), name: 'Untitled Project', color: '#E0E0E0', wallIds: [], createdAt: Date.now() };
         setProjects(prev => [...prev, newProject]);
         // Move dragged wall to new project
         handleMoveWallToProject(dragWallId, newProject.id);
         // Focus inline edit after render
       }
     }}
   >
   ```

2. **useOverviewStore 扩展：**
   ```typescript
   addProject(name: string, color?: string): string; // returns projectId
   ```

3. **InlineRenameInput 组件（新增）：**
   - Controlled `<input>` with autoFocus + selectAll
   - onBlur or onEnter → onSave(name)
   - Placeholder: "Untitled Project"
   - Max length: 50, truncate if exceeded

4. **Visual Feedback：**
   - Drag over empty grid: semi-transparent "+" overlay + text "Drop here to create project"
   - Drag over existing project header: current dashed border highlight (already implemented)
   - New project slides in with animation (scale(0.9) → scale(1))

**工作量估算：** 1.5 天

### Feature 4: Comment System Foundation (Skeleton Only)

**目标：** 评论数据结构设计 + UI skeleton（无需后端，本地存储）。

**实施计划：**

#### Data Model
```typescript
interface Comment {
  id: string;
  wallId: string;
  objectId?: string; // null for wall-level comments
  content: string;
  authorId: string; // userId of commenter
  createdAt: number;
  replies?: CommentReply[];
}

interface CommentReply {
  id: string;
  content: string;
  authorId: string;
  createdAt: number;
}
```

#### Changes
1. **useOverviewStore 扩展：**
   ```typescript
   comments: Record<string, Comment[]>; // key = wallId | `${wallId}:object:${objectId}`
   addComment(wallId: string, comment: Partial<Comment>): string;
   addReply(commentKey: string, reply: Partial<CommentReply>): string;
   deleteComment(wallId: string, commentId: string);
   ```

2. **UI Skeleton（非完整功能）：**
   - View mode 下每个 object 底部显示 "+" 按钮（Add comment）
   - Click → expands comment drawer (bottom-up panel)
   - Drawer: comment list + input field (non-functional, shows placeholder)
   - Toast: "Comments will be synced to cloud" (future feature)

3. **No Backend Yet:**
   - Comments stored in localStorage only
   - Schema ready for future Supabase integration (`comments` table)

**工作量估算：** 1 天
