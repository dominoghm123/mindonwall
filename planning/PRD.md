**状态：** ✅ 冻结（基于 Grill-Me 会话确认，2026-08-06）  
**产品标签：** Mind on Wall（工作标签；品牌命名不属于本 MVP 范围）

## 1. 产品概述

Mind on Wall 是一个桌面优先的数字手帐网页。它让有记录与表达欲、但厌倦快节奏内容消费的年轻人，把照片、想法与随手记等碎片缓慢摆放、批注并连接，沉淀为可分享的手帐成品与可回看的关系图。

旅行是首发演示场景，而非产品边界。相同交互可用于灵感 Mapping、艺术/设计研究、日常记录和手帐创作。

### 问题

现有记录工具通常把碎片压缩为时间线、相册或自动生成的长文；用户难以亲手感受碎片之间的关联，也容易被模板化叙事取代。该产品的核心价值不是提高整理效率，而是让用户通过摆放、批注和连线，重新看见被快速生活略过的感受与关系。

### 成功体验

用户应能在 3–5 分钟内完成一面墙：载入旅行样例或上传图片，摆放素材、添加纸类元素、用绳线连接关联，最后导出一张高审美的 Journal Spread 或查看 Connection Map。

## 2. 交付范围

### 本次 MVP 包含

- 桌面优先的单页网页应用（移动端不优化，能打开但体验不保证）。
- **多墙面管理**：独立的墙面总览页作为入口；初始墙 "First Mind" 预置旅行样例；新建墙面为空墙；支持重命名、管理墙多选批量删除（需二次确认）。
- 可切换的白墙墙纸背景（6 种：无墙纸纯平色 / 白色基础纸 / 米色基础纸 / 浅色粗纹纸 / 水彩纹理纸 / 牛皮纸）；没有桌面投影或任何物件阴影。
- 一键载入精心准备的旅行示例素材，以及用户本地图片上传到素材托盘、再拖到墙上。
- 四类画布物件：Picture、Paper、Stamp、Rope。
- Picture、Paper 与 Stamp 的拖拽、缩放（四角等比 + 边缘拉伸）、旋转及删除。
- **Paper 4 种变体**：普通纸（可编辑文字）、撕边纸（可编辑文字，仅边缘形状不同）、便利贴（可编辑文字，经典黄色方形，无撕边，颜色可改）、胶带（纯装饰，无文字）。
- Picture 或 Paper（**胶带 tape 除外**）被放置到墙上时，自动显示用于固定它的 **Pin**；Pin 可在 paper 范围内拖动，位置持久化（局部坐标）。
- Rope 从两个 Pin 之间创建（任意时刻可从 Pin 拖出跟随鼠标的尾巴线，松手在另一 Pin 完成，中途松手取消）；呈现带松弛弧度、无阴影的 SVG 曲线；一条 Rope 可存储一条用户输入的关联说明。
- **Connection Map 视图**（顶部 Tab 页）：忠实显示现有 Picture/Paper 节点、Rope 和关联说明；采用网格/环形自动排布（节点不重叠）；Map 是**可编辑的投影**：支持节点重排拖动、隐藏子元素，**不写回白墙数据**；Map 有**独立的撤销历史栈**。
- 可选 **AI 助手浮窗**（右侧）：关系命名 / 回顾问题 / 故事标题 / 多物件推演；输出显示为建议，用户采纳后才写入数据。
- 将当前 Journal Spread 或 Connection Map 导出为 PNG。
- 浏览器本地保存当前墙面和用户上传图片，刷新后可恢复。

### 不在本次 MVP 范围

- 云同步、账号体系、多人协作（通过 Storage Adapter 抽象层预留接口）。
- 地图、Zine、时间序列的 Live Recap。
- RSS/外部内容采集、素材商城。
- 自由手撕纸、完整物理引擎、自由绘画笔刷和任意视频剪辑。
- AI 自动添加、删除、连接、重排素材，或代写完整游记。
- AI 抠图（上传图片去背景）。
- 音频和视频主体。
- 移动端优化。
- 标签、票根等已砍掉的 Paper 变体。

## 3. 视觉与交互规范

### 白墙和质感

主界面是一面可更换墙纸的白墙，定位为私人灵感墙。整体采用干净的平面杂志拼贴感：所有物件均不使用投影。实体感仅来自纸张撕边、胶带透明纹理、印章颗粒、图钉造型及 Rope 的松弛弧度。

### 物件语法

| 物件 | 作用 | 交互 |
| --- | --- | --- |
| Picture | 照片、截图或图像化碎片 | 上传到素材托盘 → 拖到墙上；拖拽、缩放（四角等比 + 边缘拉伸）、旋转、删除 |
| Paper | 4 种变体（普通纸/撕边纸/便利贴/胶带） | 从工具栏添加；编辑文字（胶带除外）；拖拽、缩放拉伸、旋转、删除 |
| Stamp | 情绪、主题或节奏标记（印章图案） | 从预设中选择（蓝色/灰色/红色/绿色/黄色 Passport Stamp 风格）；拖拽、缩放、旋转、删除；可独立放置或附着为 Paper 的子物件 |
| Pin | 主体固定到墙面的视觉锚点 | Picture/Paper 贴墙后自动出现（默认上边缘中点）；**可在 paper 范围内拖动**，位置持久化（局部坐标）；作为 Rope 起止点 |
| Rope | 两个主体之间的可见思考路径 | 从 Pin 拖到另一个 Pin（跟随鼠标的尾巴线，松手完成/取消）；填写或编辑关联说明（双击 Rope 或 AI 浮窗）；删除 |

**Stamp 双状态规则：**
- Stamp 可独立放置于墙面，也可通过**右键菜单**选择"附着在 Paper 上"成为 Paper 的子物件。
- 附着后：Stamp 的位置转为相对 Paper 的局部坐标；缩放 Paper 时 Stamp 相对尺寸不变（一起缩放）；删除 Paper 时 Stamp **级联删除**。
- 解除附着：同一右键菜单入口"取消附着"，Stamp 保持当前绝对位置脱落。
- Stamp **无 Pin**，不能连接 Rope（独立和附着状态均不能）。

**Pin 规则：**
- Pin 默认出现在 paper 上边缘中点；可按住拖动，但**仅在 paper 范围内**移动。
- Pin 位置持久化（局部坐标），刷新后保持原位。
- Rope 端点始终跟随 Pin 位置。
- Stamp 无 Pin（独立和附着状态均无）；Tape（胶带变体）也无 Pin。

### 物件数量限制

- 单面墙最多 **50 个物件**（Picture + Paper + Stamp，Rope 不计入）。
- 达到上限时弹小弹窗提示"物件已达上限"。

## 4. 用户流程

1. 用户从总览页进入初始墙 "First Mind"（预置旅行样例），或点击"新建墙面"创建空墙。
2. 用户在白墙上摆放 Picture（从素材托盘拖入）；从工具栏添加 Paper 和 Stamp，并编辑 Paper 中的文字。
3. 系统自动显示 Pin；用户可在两个 Pin 之间创建 Rope，并可输入关联原因。
4. 用户点击顶部 Tab 切换到 Connection Map。该视图保留原有节点和关系，以网格/环形排布、统一节点尺寸和更高对比度展示；隐藏墙纸和装饰性 Paper 纹理；**Map 支持轻量编辑**（拖动重排、隐藏子元素），编辑不写回白墙；Map 编辑有独立撤销栈。
5. 用户可打开右侧 **AI 助手浮窗**，选择任务类型（关系命名/回顾问题/故事标题/推演）和操作对象，AI 输出以建议形式展示；用户采纳后写入数据（关系命名→Rope note、故事标题→墙标题、回顾答案→便利贴落点）。
6. 用户导出 Journal Spread 或 Connection Map 的 PNG。

### 素材上传流程

- 用户上传图片到**左侧素材托盘**（hover 展开）→ 再从托盘拖到墙上。
- 上传限制：单文件 ≤ 10 MB；用户图片总计 ≤ 12 张/全局（素材托盘全局共享）。
- 样例素材作为应用内静态资源提供，不计入配额。

## 5. AI 行为

AI 是可选的叙事陪伴，不是作者。调用时，应用仅发送用户选择的 Picture/Paper 文本、Rope 关联说明及用户的所选任务。AI 输出必须显示为"建议"，用户采纳后才写入数据。

**入口：** 右侧 AI 助手浮窗（统一入口），用户选择任务类型和操作对象。

**四种任务：**

| 任务 | 触发 | 结果 | 采纳后写入 |
| --- | --- | --- | --- |
| 关系命名 | 浮窗内显示"点选墙上 Rope"模式 → 用户点选 Rope | AI 生成短名称；也可直接打字命名 | Rope note |
| 回顾问题 | 选中若干物件（Ctrl/Cmd 多选/框选）→ 选任务 | AI 生成反思问题；可点击按钮生成便利贴（Paper 变体）放于物件旁空位，并自动创建 Rope 连接多个物件 | 展示于浮窗；采纳后自动保存 |
| 故事标题 | 选任务（无需选中特定物件） | AI 生成诗性标题 | 墙标题字段（与用户重命名同字段，两种来源） |
| 多物件推演 | 选中多个物件 → 选任务 | 针对多物件提出反思/思考（MVP 暂 = 回顾问题） | 同回顾问题 |

**采纳机制：** 输出右下角有"采纳"按钮。采纳→持久化保存进 localStorage；未采纳→丢弃。回顾问题例外：展示即自动保存，点"取消"才丢弃。

**失败处理：** AI 超时、失败或未配置：Map、画布和导出仍可使用；显示"稍后再为这面墙命名"。

## 6. 技术设计

### 技术选型

- React + TypeScript + Vite：单页应用与可维护的组件边界。
- DOM：呈现 Picture、Paper、Stamp 与可编辑文字，便于选择、变换和导出。
- SVG：绘制 Rope 的 Bézier 曲线和 Connection Map 连线。
- Zustand：存储物件、自动 Pin、Rope、墙纸、视图和导出状态。
- **Storage Adapter 抽象层**：底层为 localStorage + IndexedDB（当前墙面 JSON + 图片二进制），接口预留云同步扩展能力（MVP 不实现云同步）。
- `html-to-image` 或等效 DOM 截图方案：导出 PNG。
- Vercel Serverless Function：提供单一 `/api/story` 路由，代理对阿里云百炼 Qwen API 的调用；部署时 API Key 仅配置在 Vercel 环境变量中。

### 数据模型

- **`Wall`**：`id`、`name`（墙标题）、`wallpaper`（墙纸）、`items`（物件列表）、`ropes`（Rope 列表）、`undoStack`（撤销历史，持久化）、`mapViewState`（Map 编辑状态，持久化）。
- **`Item`**：`id`、`type`（picture/paper/stamp）、`x`、`y`、`width`、`height`、`rotation`、`variant`（paper 变体）、`parentId`（可选，Stamp 附着时的 Paper ID），以及类型对应内容字段：Picture 存 `assetId`，Paper 存 `text` + `color`（便利贴颜色），Stamp 存 `stampId`。
- **`Asset`**：`id`、`mimeType`、`byteSize`、`storageKey`；图片二进制数据保存在 IndexedDB，墙面 JSON 只保存 `assetId`。素材托盘全局共享。
- **`Pin`**：由 `itemId` + 局部坐标（相对物件）推导生成；位置可拖动并持久化；不单独作为独立物件。
- **`Rope`**：`id`、`fromItemId`、`toItemId`、`note`。Rope 端点不持久化，始终从两端物件的 Pin 推导。
- **`mapViewState`**：节点手动位置、隐藏的子元素列表、Map 独立撤销栈。

### 撤销机制

- 白墙：Ctrl+Z / Ctrl+Shift+Z（重做）；**有限深度**（20 步），快照式记录（仅存操作类型 + 受影响物件的前后状态）。
- **图片上传/删除不进撤销栈**；删除图片需用户手动删，恢复需重新上传。
- 刷新后撤销历史仍可用（持久化）。
- Map：与白墙**独立**的撤销历史栈；Map 编辑不写回白墙。

### 多墙面数据

- 墙面列表存储在 localStorage（JSON 数组，每项含 id/name/wallpaper/items/ropes/undoStack）。
- 初始墙 "First Mind" 在首次启动时创建，预置旅行样例（6 张图片 + 若干普通纸/撕边纸/便利贴 + 3 条胶带）。
- 新建墙面为空墙。
- 删除墙面需二次确认（总览页"管理墙"功能）。

### 画布交互

- **缩放**：鼠标滚轮 = 缩放；触控板双指缩放。范围 20%–300%。
- **平移**：鼠标左键拖背景 = 平移；触控板：先长按选中物体 + 另一手指拖拽。
- **初始视图**：空墙固定 100%；有内容时自适应呈现包含全部物件的缩略视图。
- **多选**：Ctrl/Cmd 点击多选 + 矩形框选 + Delete 键删除。

### 导出规则

- **范围**：所有物件的包围盒（不是视口）；限制尺寸上限；桌面网页比例。
- **内容**：墙纸 + 物件 + **Pin** + Rope，背景不透明。
- **Map 导出**：Map 界面全图导出。

### 失败处理

- 不支持、损坏、超过 10 MB 的图片，或超出 12 张用户图片限制：显示可理解的错误提示，不改变当前墙面。
- 生成 Rope 时未命中另一个有效 Pin：不创建无效 Rope。
- 删除关联主体会删除相连 Rope；Stamp 附着时级联删除。
- 浏览器本地存储不可用：提醒用户本次内容不会自动保留，但不阻止创作和导出。
- IndexedDB 配额已满：保留已显示的当前墙面，停止自动保存并提示。

## 7. UI 架构

### 双层浮窗布局

- **底层**：墙面画布（无限滚动 + 缩放/平移）。
- **上层浮窗**（默认缩进/缩小，hover 展开；参照 Procreate 风格）：
  - **正下方工具栏**：所有元素工具（Picture/Paper/Stamp/Rope 创建）；默认缩小，hover 弹起向左右延展。
  - **左侧素材托盘**：纵向居中，默认缩进，hover 向右展开；全局共享，不随墙面切换变化。
  - **顶部浮窗**：墙名、退出墙面（返回总览页）、保存状态指示、墙纸设置（6 种选项）、Connection Map Tab。
  - **右侧 AI 助手**：AI 浮窗，展示任务类型和操作对象。
  - **选中便利贴时**：底部工具栏出现颜色选项（几个常见颜色单选 + 自定义色盘）。

### 总览页

- 独立的墙面总览页作为入口。
- 显示所有墙面的卡片（含墙名 + 墙纸预览 + 物件缩略）。
- "管理墙"按钮：进入多选模式，支持批量删除（需二次确认）。
- "新建墙面"按钮：创建空墙。

- 所有打包进应用的素材必须为用户自有、生成素材或允许再分发的素材；在 `manifest.json` 中记录每项来源与许可状态。

1. 对数据变换做单元测试：Pin 推导、Rope 有效性、级联删除、持久化恢复、撤销栈。

## 10. 参赛定位

提交的应用是一个网页应用。Qoder 用于构建前后端与高自由度画布交互；阿里云百炼 Qwen 仅用于可选、用户主导的叙事辅助。秒哒不作为本 MVP 的主开发平台。

### 架构演进预留

- **Storage Adapter**：当前底层为 localStorage + IndexedDB；接口设计支持后续无缝接入云同步（账号体系 + 多用户数据分发）。
- **AI 抠图**：MVP 不做；后续利用百炼图片编辑能力实现。
- **Stamp 文字编辑**：一期纯视觉；二期支持 Stamp 内文字替换（已预留接口）。
- **多物件推演**：MVP 暂等于回顾问题；后续迭代为独立任务。
- **地点识别**：后续迭代通过 Paper 文字识别坐标。

## 11. v0.2 修订记录（2026-08-07，用户确认）

### 内页（Wall Editor）

- **颜色**：除 Picture 外所有物件（Paper 各变体、Stamp）支持右键改颜色；提供预设色板 + 自定义调色盘（color picker）。
- **缩放**：Paper 上的文字随 Paper 同比缩放；独立 Stamp 不随多选群组缩放，附着在 Paper 上时才跟随 Paper 等比变化。
- **旋转**：新放置素材默认 rotation = 0（垂直不倾斜）；长按选中框顶部区域后拖动进入旋转，松手停止；接近 0°/90°/180°/270°/360° 时磁性吸附产生明显停顿，便于转整角。
- **浮窗**：底部工具栏默认隐藏，鼠标 hover 底部时从下往上浮出；右下角缩放/Map 浮窗位置不变，静止时默认隐藏，hover 时由右向左浮出。
- **上传**：Image/Paper/Stamp 面板均有 Upload 入口；上传素材不直接上墙，先存入素材库，在次级浮窗中可见，点击缩略图才添加到墙上。
- **物件**：Stamp 与 Tape 都不加 Pin；Stamp 素材改为透明背景矢量绘制（弃用白底 PNG）；Tape 与 Torn Paper 增加更多色彩变体。
- **墙纸**：新建墙默认墙纸为白色（white）。
- **Rope**：点击连线模式；扩大命中范围（点击带 Pin 物件任意区域等同点击其 Pin），点击空白才取消。

### 主页（Overview）

- **三点菜单**：固定位于卡片**右下角**（硬要求）。
- **头像入口**：顶栏最右侧为头像入口（内页与主页一致），下拉菜单至少包含：Profile（用户主页）、Materials（个人素材库，可上传与加工素材）、Settings（设置，含首页背景）。
